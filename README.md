# 3D 照片墙

画面由两层组成：

- **爱心粒子云**：三千颗玻璃质感的红色珠子，堆成一颗**真正有厚度**的心形
  （中间厚、边缘薄、前后一样鼓，转到侧面也是实的），
  张手散开就变成满屏虚化光斑 —— 远处是清晰的小火星，近处是化开的大光斑
- **照片卡**：真实的照片和视频封面沿一条**绕心的轨道慢慢转**，
  一会儿转到前面挡住心口，一会儿沉到背面 —— 照片始终大致朝着镜头，看得清内容
- 心形背后一层红雾 + 每颗珠子外面一层微光，整颗心是「在发光」的

手势：握拳聚合 · 张手散开 · **捏住看大图（松手自动关闭）** · 手掌平移转动。

**手势说明随时可看**：点底栏的「? 说明」（快捷键 `?`）就把说明卡调出来，不用开摄像头也能看。
首次打开摄像头时会自动弹一次，认出手势后自动收起，不挡画面。

全部本地运行、不联网：three.js、手部识别模型、运行时都放在 `vendor/` 里。

## 一、怎么打开

**双击 `启动.bat`**（唯一正确的方式，所有功能都能用）

它会：
1. 自动找电脑上的 Python（`py -3` / `python` / `python3` / 常见安装路径都试一遍）
2. 起一个只监听本机的服务（默认 `http://127.0.0.1:8765/`，端口被占就自动往后找）
3. **服务真的起来之后**再自己打开浏览器 —— 所以不会再白屏、也不会打开成 `file://`

那个黑窗口别关，关掉就是停止服务。想换电脑看，整个文件夹拷过去、装个 Python 再双击即可。

### 为什么不直接双击 index.html

浏览器把 `file://` 当成不安全来源：摄像头不给、视频可能不给、文件夹清单读不到。所以直接双击 `index.html` 时，页面顶上会出现一条红色提示条，告诉你改用 `启动.bat`。（示例照片还是能看的，只是手势、视频、自动读文件夹都不行。）

## 二、放自己的照片 / 视频

把文件丢进 **`media/`** 文件夹就行，**不用改代码、数量不限**：

```
media/
├── 001.jpg
├── 002.png
├── 婚礼.mp4        ← 视频也支持
└── 2024/           ← 子文件夹也会被读到
    └── a.jpg
```

- 支持图片：`jpg / jpeg / png / webp / gif / bmp / avif`
- 支持视频：`mp4 / webm / mov / m4v / ogv`
- **每次刷新都会重新扫描并随机排序**，同一批照片每次打开顺序都不一样
- 面板里的「换一批」= 重新扫描 + 重新打乱

场景里**同时**摆几张，由面板里的 **「同时展示」滑杆**决定（6–48 张，默认 20）。其余文件不会丢，用「上一张 / 下一张」照样能翻到全部。

> 视频封面是浏览器现场抽的第一帧，卡片左下角会有 ▶ 角标；点开就是真正的视频播放器，能播、能拖进度条（`server.py` 做了 Range 支持）。

## 三、手势怎么玩

点底部 **✋ 手势**（或按 `H`）→ 允许摄像头 → 把手放进画面里。

左下角会出现摄像头预览，手部骨架实时画出来，下面一行字告诉你当前识别到的手势。

| 手势 | 会怎样 | 触发方式 |
|---|---|---|
| ✊ **握拳** | 照片聚合成心形 / 文字 | 握住保持 0.3 秒 |
| 🖐 **张手** | 散开成满天星 | 五指张开保持 0.3 秒 |
| 🤏 **捏住** | 打开大图（视频直接播） | 拇指食指**一直捏着**，图就一直开着 |
| 🤏 **松开** | 关掉大图 | 手指一松开就自动收起 |
| 👋 **左右移动** | 转动整片星空 | 手在画面里平移 |

> 说明卡在桌面端是左下角一小块，手机端是贴着底栏上方的一条浮层。
> 点底栏「? 说明」或按 `?` 可以反复调出来；按 `ESC` 或点「知道了」收起。

要点：
- **光线要够**，别背光站着，手掌要完整在画面里
- 捏合是「按住」逻辑，像按一个实体按钮：**捏住看图、松手关闭**；每捏一次自动换下一张
- 捏的时候其余手指自然舒展（张开度 >0.34），否则会被当成握拳去聚合
- 握拳时拇指也贴着食指，所以用「五指张开度」把两者分开，**握拳不会误触开图**
- 手离开画面 0.35 秒会自动松手，图不会一直挂着

## 四、配置面板（⚙ 或按 `S`）

右侧面板改完立即生效，并记在浏览器本地（下次打开还在）：

- **文字**：标题、副标题、是否显示副标题
- **布局模式**：心形 / 文字（文字内容随便填，比如 `2026`、`我爱你`、`新年快乐`）
- **照片 / 视频**：当前扫描到多少文件、导入本地文件、换一批、**同时展示几张**
- **背景音乐**：音量（把音乐命名为 `music/bgm.mp3`）
- **摄像头**：镜像开关
- **画面**：转动速度、镜头尺寸、雾化、星光

「恢复默认」一键回到初始状态。

## 六、文件结构

```
Photo-display/
├── 启动.bat            ← 双击这个
├── server.py           ← 本地服务 + 自动扫描 media/（带 Range 支持）
├── index.html
├── style.css
├── app.js              ← 粒子云、形状、照片卡、交互
├── gesture.js          ← 摄像头手势（MediaPipe HandLandmarker，懒加载）
├── media/              ← 你自己的照片和视频放这里
├── music/              ← 放 bgm.mp3
├── vendor/
│   ├── three.min.js
│   └── mp/             ← 手部模型 + wasm（约 49MB，全部本地）
└── photos/
    ├── demo-data.js    ← 直接开 index.html 时的兜底示例图
    └── manifest.json   ← 可选：不用服务时手动列文件名
```

## 七、常见问题

**双击了 `启动.bat`，打开的网页还是提示「手势需要本地服务」**
看一眼地址栏：如果还是 `file:///D:/...`，说明浏览器打开的是旧标签页。把这个标签关掉，
回到那个黑窗口看看写的是什么地址（一般是 `http://127.0.0.1:8765/`），直接复制到浏览器也行。

**黑窗口一闪就没了**
说明没找到 Python。装一个 Python（安装时勾上 `Add python.exe to PATH`）再双击。

**点手势一直提示「加载中 / 脚本没加载出来」**
说明页面是 `file://` 打开的（见上）。模块和摄像头在 `file://` 下都会被浏览器拦掉。

**不知道手势怎么比**
点底栏「? 说明」（或按 `?`），说明卡上有四个动作和两个注意事项。开摄像头时会自动弹一次。

**摄像头打不开 / 提示权限被拒**
点浏览器地址栏左边的相机图标 → 允许 → 刷新。必须用 `http://127.0.0.1` 打开。

**画面里没有照片，只有星星**
`media/` 是空的，或者文件后缀不认识。放几张 jpg 进去，点「换一批」。

**视频卡片是灰的 / 没有画面**
个别编码浏览器解不了（比如某些手机拍的 HEVC）。转成 H.264 的 mp4 最稳。

**有点卡**
面板里把「同时展示」调小（比如 10–14 张）。手机端上限 24 张。
如果还是很卡，多半是显卡在跑软件渲染：换成 Chrome / Edge，并在设置里打开「使用硬件加速」。

**想发给朋友看**
把整个文件夹打包发过去，对方装个 Python 双击 `启动.bat` 即可。要真正在线分享得传到服务器或用静态托管（那种情况下手势需要 HTTPS 才能开摄像头）。
